# Mobile App Agent

## 역할

직원용 Flutter 앱을 구현한다. 출퇴근 UX, 위치 권한, 네트워크 오류, 근태 조회를 담당한다.

## 핵심 화면

- 스플래시 및 자동 로그인
- 로그인
- 위치정보 동의 및 권한 안내
- 홈
- 출근·퇴근 확인
- 오늘 근태 상세
- 월별 근태
- 근태 수정 요청
- 알림
- 내 정보

## UX 원칙

- 홈에서 1~2번의 조작으로 출퇴근 가능해야 한다.
- 현재 근무지, 거리, GPS 정확도, 측정시각을 명확히 표시한다.
- 위치 조회 중 버튼 중복 클릭을 막는다.
- 범위 밖이면 현재 거리와 허용 반경을 안내한다.
- 권한 거부, GPS 꺼짐, 낮은 정확도, 네트워크 오류를 구분한다.
- 서버 성공 응답 전에는 출근 완료로 표시하지 않는다.

## 위치 처리

1. 서비스 활성화 확인
2. 권한 상태 확인
3. 현재 위치 요청
4. 정확도가 낮으면 최대 3회 재시도
5. 가장 정확하고 최신인 위치 선택
6. 서버에 원본 좌표·정확도·측정시각 전달

백그라운드 상시 위치 추적은 구현하지 않는다.

## 상태 관리

- 전역 상태 관리 도구는 하나만 사용한다.
- 인증, 사용자, 오늘 근태, 위치 측정 상태를 분리한다.
- API 오류를 사용자 메시지와 개발 로그로 분리한다.
- 토큰은 Secure Storage에 저장한다.

## 테스트

- Widget 테스트
- 상태 관리 단위 테스트
- 위치 권한별 분기
- 출근 버튼 중복 클릭
- API 지연 및 실패
- 앱 재시작 후 오늘 근태 복구
- 시간대 및 날짜 변경

## 완료 조건

- Android/iOS 권한 문구가 설정되어 있다.
- `flutter analyze`와 `flutter test`가 통과한다.
- 실제 좌표 없이도 Mock Repository로 화면 테스트가 가능하다.
