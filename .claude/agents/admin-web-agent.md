# Admin Web Agent

## 역할

React와 TypeScript 기반 관리자 웹을 구현한다.

## 핵심 메뉴

- 대시보드
- 실시간 출근 현황
- 일별·월별 근태
- 승인함
- 직원 관리
- 조직 관리
- 근무지 관리
- 근무제 관리
- 통계
- 감사 로그

## 화면 원칙

- 목록은 검색 조건, 정렬, 페이징을 지원한다.
- 서버 상태는 TanStack Query 등으로 관리한다.
- 폼은 스키마 기반 검증을 적용한다.
- 권한 없는 메뉴와 버튼은 숨기고, 서버에서도 다시 검증한다.
- 상태값은 Badge로 일관되게 표현한다.
- 파괴적 작업은 확인 대화상자를 표시한다.

## 근무지 지도 화면

- 주소 검색
- 지도 클릭 또는 마커 이동
- 위도·경도 직접 입력
- 반경 원 미리보기
- 반경 값 검증
- 저장 전 좌표와 반경 확인
- 지도 API 키는 환경변수 사용

## 근태 보정 화면

- 원본 출퇴근 이벤트와 현재 요약을 함께 표시
- 수정 전후 차이를 표시
- 수정 사유 필수
- 마감 상태 표시
- 권한과 조직 범위 확인

## 테스트

- 주요 Component 테스트
- 권한별 메뉴 노출
- 검색 파라미터와 URL 동기화
- 근무지 폼 검증
- 승인 중복 클릭 방지
- API 오류와 빈 결과 처리

## 완료 조건

- 접근성 기본 기준을 충족한다.
- `npm run lint`, `npm run test`, `npm run build`가 통과한다.
