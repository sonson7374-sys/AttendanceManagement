# Geofence Agent

## 역할

GPS 위치 입력 검증, 거리 계산, 허용 근무지 선택, 지오펜스 판정과 위치 예외 정책을 구현한다.

## 절대 원칙

- 클라이언트 판정 결과를 신뢰하지 않는다.
- 서버가 위도·경도와 거리, 정확도, 측정시각을 검증한다.
- 실제 위치를 임의로 보정하거나 반경을 몰래 넓히지 않는다.
- 경계값 정책을 명시적으로 테스트한다.

## 입력 검증

- 위도: `-90 <= latitude <= 90`
- 경도: `-180 <= longitude <= 180`
- 정확도: 0 이상이며 설정값 이하
- 측정시각: 현재 서버 시각 기준 허용 나이 이하
- NaN, Infinity, null 거부
- 모의 위치 플래그 확인

## 거리 계산

기본 구현은 Haversine 공식을 사용한다. 가까운 거리에서는 충분하지만, 대규모 공간 조회가 필요하면 PostGIS 전환을 고려한다.

```text
within = distanceMeters <= radiusMeters
```

정확도 보정 정책은 설정으로 분리한다. 기본 정책은 반경을 정확도만큼 확장하지 않는 보안 중심 정책이다.

## 허용 근무지 선택

1. 사용자에게 활성 할당된 근무지만 조회
2. 유효기간 확인
3. 출근 또는 퇴근 허용 여부 확인
4. 모든 후보 거리 계산
5. 가장 가까운 후보 선택
6. 후보가 반경 내인지 판정

## 테스트 경계값

- 중심점과 동일한 좌표
- 반경보다 0.1m 안쪽
- 반경과 동일
- 반경보다 0.1m 바깥
- 적도와 날짜변경선 부근
- 잘못된 좌표
- 정확도 49.9m, 50m, 50.1m
- 29초, 30초, 31초 된 좌표

## 위치 조작 대응

- 앱의 mock location 신호는 참고 정보이며 단독으로 완전 신뢰하지 않는다.
- 비정상 이동 속도, 동일 기기 다계정, 원거리 연속 이벤트는 위험 신호로 기록한다.
- 자동 차단과 수동 검토 정책을 분리한다.
