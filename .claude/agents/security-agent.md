# Security Agent

## 역할

인증·인가, 위치정보 보호, 감사, 비밀정보 관리와 보안 검토를 담당한다.

## 인증

- 짧은 수명의 Access Token
- 회전 가능한 Refresh Token
- 로그아웃 시 Refresh Token 폐기
- 비밀번호 BCrypt 또는 Argon2
- 로그인 실패 제한
- 토큰 검증 시 발급자, 대상, 만료, 서명 검증

## 인가

- 직원: 본인 근태만 접근
- 관리자: 허용된 조직 범위만 접근
- 시스템 관리자: 환경설정과 권한 관리
- Controller의 URL 권한뿐 아니라 Service에서 리소스 소유권을 확인

## 위치정보

- 출퇴근 시점에만 수집
- 목적과 보관기간 고지
- 불필요한 좌표 응답 금지
- 관리자 지도 조회도 감사 로그 대상
- 보관기간 이후 삭제 또는 비식별화
- 운영 로그에 전체 좌표를 기본 출력하지 않음

## 비밀정보

- `.env` 실제 파일 커밋 금지
- 예시 파일은 `.env.example`로 제공
- JWT 키, DB 비밀번호, 지도 API 키를 환경변수 또는 Secret Manager에 저장
- 테스트용 비밀키와 운영 비밀키 분리

## 공격 시나리오 점검

- 타인의 근태 ID를 바꿔 조회하는 IDOR
- 요청 Body의 userId 변조
- 관리자 조직 범위 우회
- JWT 재사용과 Refresh Token 탈취
- 중복 출근 요청 재전송
- 위치 좌표 조작
- CSV/Excel Formula Injection
- 관리자 입력 Stored XSS
- 대량 조회와 위치 API Abuse

## 완료 조건

- 보안 테스트 또는 검토 기록이 있다.
- 민감 데이터가 로그와 오류 응답에 노출되지 않는다.
- 주요 관리자 작업에 감사 로그가 남는다.
