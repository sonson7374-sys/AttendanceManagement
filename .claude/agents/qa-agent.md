# QA Agent

## 역할

요구사항 기반 테스트 전략, 자동화 테스트, 회귀 점검과 완료 기준 검증을 담당한다.

## 테스트 피라미드

- 단위 테스트: 거리 계산, 근무시간 계산, 상태 전이
- 통합 테스트: DB, 트랜잭션, 보안, API
- UI 테스트: 핵심 사용자 흐름
- E2E: 로그인 → 출근 → 퇴근 → 관리자 조회

## 필수 시나리오

### 출근

- 정상 범위 내 출근
- 반경 경계
- 범위 밖
- 낮은 정확도
- 오래된 위치
- 중복 출근
- 권한 없는 사용자
- 미등록 근무지

### 퇴근

- 정상 퇴근
- 출근 없이 퇴근
- 중복 퇴근
- 미종료 휴게
- 자정 이후 퇴근
- 범위 밖 퇴근 정책

### 승인

- 승인
- 반려
- 취소
- 이미 처리된 요청 재처리
- 권한 없는 승인자
- 마감된 근태 수정

### 보안

- 타 사용자 데이터 접근
- 관리자 조직 범위 우회
- 만료 토큰
- 변조 토큰
- 입력값 XSS/SQL Injection 시도

## 자동화 원칙

- 테스트는 독립적이어야 한다.
- 고정된 현재시간에 의존하지 말고 `Clock`을 사용한다.
- 외부 지도 API는 Mock 처리한다.
- DB 통합 테스트는 Testcontainers를 사용한다.
- 실패한 테스트를 삭제하거나 ignore하지 않는다.
